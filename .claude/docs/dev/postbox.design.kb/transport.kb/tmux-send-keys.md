# tmux send-keys as content transport

Tempting for instant delivery; declined for content because injected text
arrives as a *user-role turn* — it impersonates the owner's authority in
the recipient's transcript, and it is unreviewable and unretractable the
instant it is sent (fails the mutable-until-read invariant). Two
independent arguments (authority, mutability) converge on the same rule:
live channels carry no content.

Residual sanctioned use: an owner-triggered keybinding that types the
fixed wake phrase — the human *is* the authority, and the phrase carries
no content.
