# The `claude agents` / Agent-tool interface

Owner veto, verbatim: "I hate the `claude agents` interface. Like, a lot.
… let's keep it simple: I refuse to use it."

Ground: the interface, not the economics. The measured subagent win is
three properties — lean context, cheaper carrier model, artifact
quarantine — and any transport with those properties collects it (tmux
worker windows with `/clear` discipline, `claude -p` one-shots, postbox
workers). Preserved advantages the interface never had: workers are real
terminals (watchable, interruptible, survive the driver).

Revisit condition: none foreseeable (standing veto).
