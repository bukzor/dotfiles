# Where to codify spectrum-not-singular

The principle (`../../spectrum-not-singular.md`) was proposed but
its location was not finalized. Each file in this collection is one
candidate location, with the tradeoffs that distinguish it from the
others.

## What belongs here

One file per genuinely distinct candidate location. A "candidate"
must be a real codification site that Claude reads in its loading
sequence. Combinations (e.g., short-rule-here-plus-detail-there) are
their own candidate, not a sum of others.

## What does NOT belong

- Sub-variants of a candidate that don't change the location (e.g.,
  different wordings of the same rule in CLAUDE.md) — those go in
  the candidate's file as alternatives within
- Locations that aren't actually loaded by Claude in the relevant
  context (e.g., a file no one reads) — those aren't candidates
