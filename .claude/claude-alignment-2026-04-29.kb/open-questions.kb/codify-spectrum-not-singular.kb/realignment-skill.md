# Candidate: embedded in `claude-realignment` SKILL.md

Place spectrum-not-singular inside the realignment skill's Posture
section, treating it as the operating principle that the skill's
calmed-state re-entry implements. Already partially present: the
session-end edit of the skill includes "Re-run with increased
attention to the literal" guidance that draws on the same idea.

The fit is good if spectrum-not-singular's primary use is
post-breakdown re-parsing. The skill loads when frustration signals
fire, which is exactly when the principle is most needed — Claude
under rejection pressure, where the failure mode is "fire a new
confident guess."

The cost is that the principle's universality is wasted. Spectrum-
not-singular applies to *every* parse, not only to parses that are
being re-done after a breakdown. Embedding it in the realignment
skill means it's only operative *after* failure, not *before*.
That's a strict subset of the principle's intended scope.

The combination candidate (`multi-location.md`) addresses this by
keeping the realignment skill as a heavy-detail location while
also placing a short ambient rule in CLAUDE.md.
