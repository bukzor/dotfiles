# User Conventions

What the user expects of Claude in interpretation, response, and topic
management. Each item describes a single convention.

## What belongs here

A convention belongs here when it describes how the user communicates
or interprets, in a way that affects how Claude should parse or respond.
Conventions are descriptive of the user's actual patterns, not normative
prescriptions Claude is choosing to follow.

## What does NOT belong

- Failure modes the prior Claude noticed in itself (those go in
  `../failure-modes.kb/`)
- Action items or codification work (this kb does not hold plans)
- Conventions that are already codified live in
  `~/.claude/CLAUDE.md` or `~/.claude/must-read.d/` and are reliably
  triggering — link to them from the relevant convention file rather
  than duplicating
