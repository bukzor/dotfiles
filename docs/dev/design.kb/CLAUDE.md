# design.kb -- where a new file goes

A subsystem's design -> `<subsystem>.md` (its defining theory: ontology,
stale-when) beside `<subsystem>.kb/`, holding the rungs it argues about
as theories (`goals.md` + `goals.kb/` ...) and single claims as bare
`X.md`. The argument a design rests on is a flat ledger in `../`
(`*.claims.md`); cite its labels in `why:`, never copy its text.
