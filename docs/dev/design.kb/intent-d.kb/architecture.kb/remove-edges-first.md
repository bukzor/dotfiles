# An ordering is removed before it is represented

A load-time read becomes a function or a defaulted read; a
non-commutative write becomes an append to one array or a single
owner. What survives (`keybinds` on `zkbd`, `zkbd` on `TERM`,
`completion` on `HOMEBREW_PREFIX`) is what the tree spells.
