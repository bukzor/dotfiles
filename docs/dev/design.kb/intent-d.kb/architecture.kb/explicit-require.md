# A prerequisite the tree cannot spell is a `require X` line in the leg

The true relation is a DAG with in-degree above one (`path` needs
several tool intents), which a tree misstates; the leg declares the
edge and the loader sources X's legs once, on demand. Expected count
after COMMUTE: zero or one.
