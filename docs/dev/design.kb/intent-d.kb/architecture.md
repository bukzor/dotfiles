# Architecture

What the tree is. **Nesting** is a directory inside an intent;
**require** is a leg's explicit declaration of a prerequisite;
**series-parallel** names the class of orders the tree alone can
spell. Mechanism (the loader's lines, the entry points) is one rung
down.
