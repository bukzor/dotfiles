# Channels

The attention channels actually wired up on this machine, right now,
each judged by what `principles.kb/` says makes a channel reach its
population. An inventory, not a design doc: when a channel is added,
removed, or rewired, this theory updates in the same change -- per
`ATTENTION`'s `stale-when`, an inventory that drifts from
`.config/sh/rc.d/`, `.tmux.conf`, and `.config/anacron/` is exactly
the failure mode this ledger exists to prevent recurring.
